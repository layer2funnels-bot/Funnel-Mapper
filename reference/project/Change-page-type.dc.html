What changes: type label, icon, page-type wireframe, and any type-specific Detail fields (e.g. a Webinar gains date/time; a Quiz gains question count). What stays: the block's id, canvas position, incoming and outgoing connections, its URL and captured thumbnail, build status, and all recorded analytics.  ·  Fields with no equivalent in the new type are preserved in the block's data but hidden, so switching back restores them.  ·  One ⌘Z reverts the whole change. Math-neutral: conversion still flows through the same node.
