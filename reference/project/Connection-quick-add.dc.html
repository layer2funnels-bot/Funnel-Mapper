Endpoint & edge cases
Cancel

Esc or click away closes Quick Add and discards the dragged connection. No node is created, nothing is autosaved.

Invalid target

If the dragged port can only connect to specific families, unsupported options dim in the list and the connector tip turns amber — the release still opens Quick Add, but only valid blocks can be chosen.

Undo / redo & autosave

Creating via Quick Add is one atomic action: a single ⌘Z removes both the new block and the new edge. Autosave fires once, after the block lands.

Release on an existing block

Dropping the connector onto a block's open input port connects to it directly and skips Quick Add — the existing drag-to-connect behaviour, unchanged.

Build notes

Reuses the library's search + family grouping; the Quick Add list is the library, filtered to blocks valid from the source port.

Recents and the client's Pinned products appear first, above the family sections, exactly as in the left library.

New block spawns at the release point already connected; selection and inspector move to it so the user keeps editing without a second click.
